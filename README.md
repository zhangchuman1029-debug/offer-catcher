# Offer 捕手

学生求职匹配智能体 Demo，覆盖职业画像构建、岗位匹配、简历优化和求职成长路线图。

## 本地预览

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://127.0.0.1:4173
```

## 文件说明

- `index.html`：Demo 页面结构
- `loading.html`：AI 分析加载页
- `profile.html`：职业画像结果页
- `jobs.html`：岗位匹配结果页
- `resume.html`：简历优化结果页
- `roadmap.html`：成长路线结果页
- `styles.css`：界面样式
- `app.js`：岗位库、匹配评分和交互逻辑
- `offer-catcher-solution.md`：1000 字以内方案说明

## 部署

这是纯静态项目，可部署到 GitHub Pages、Vercel、Netlify 或任意静态托管平台。
